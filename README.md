# To-Do List Web Application

Welcome to my **To-Do List** web application! This project is designed to help users manage their daily tasks efficiently. It is a simple yet powerful tool for organizing to-do items with an intuitive and user-friendly interface.

## Features:
- **Add Tasks:** Quickly add tasks with just a few clicks.
- **Edit Tasks:** Modify your tasks if your priorities change.
- **Delete Tasks:** Easily remove tasks when they're completed or no longer needed.
- **Task Completion:** Mark tasks as completed with a click, and they will be visually distinguished from ongoing tasks.
- **Responsive Design:** The application works smoothly on both desktop and mobile devices.
- **Local Storage:** Tasks are stored in the browser’s local storage, ensuring they persist even after you refresh or close the app.

## Tech Stack:
- **Frontend:** HTML, CSS, JavaScript
- **Framework:** React (optional if you used it)
- **Other Tools:** Local Storage, Git, GitHub

## Installation Instructions:
If you'd like to run this project locally, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/Prince-2028/ToDoList.git
    ```

2. Navigate to the project directory:
    ```bash
    cd ToDoList
    ```

3. Install the necessary dependencies:
    ```bash
    npm install
    ```

4. Run the app locally:
    ```bash
    npm run dev
    ```
